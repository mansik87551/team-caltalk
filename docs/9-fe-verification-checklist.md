# FE 통합 검증 체크리스트 (FE-14)

핵심 시나리오(SC-01~06) end-to-end 해피패스와 반응형(NFR-08)·교차 브라우저(NFR-07) 마감 검증용 체크리스트다.
자동화된 해피패스 일부는 `client/src/pages/workspace.e2e.test.tsx`로 회귀 검증한다.

## 1. 시나리오 해피패스 (SC-01~06)

- [ ] **SC-01 로그인/진입**: 회원가입 또는 로그인 → 토큰 저장 → 워크스페이스(헤더에 사용자명·역할) 진입.
- [ ] **SC-02 일정 등록**: 팀장이 `일정 추가` → 모달에서 제목·시작/종료 입력(로컬 KST) → 저장 → 모달 닫힘 → 캘린더 반영(KST 표시).
- [ ] **SC-03 충돌 경고**: 겹치는 일정 등록 → 201 저장 + 모달/토스트에 `conflicts[]` 경고(차단 아님, BR-08).
- [ ] **SC-04 날짜 동기화**: 캘린더 날짜 클릭 → 채팅 패널이 해당 `targetDate` Daily Chat Log 로 동기화 → 메시지 전송 시 selectedDate 가 targetDate 로 부여.
- [ ] **SC-05 변경요청 생성/확인**: 팀원이 일정 클릭 → 변경 요청(content) → 서버가 메시지 생성·`originMessageId` 연결 → 팀장 목록에서 확인.
- [ ] **SC-06 처리(반영/반려)**: 팀장이 반영(start/end) 시 일정 반영·요청 `applied` / 반려 시 `rejected`+사유 표시. 종결 요청 재처리 버튼 비활성(AC-08).

## 2. 시간 정합 (UTC↔KST, FE-05)

- [ ] 일정 입력(KST) → 전송 UTC → 캘린더 표시 KST 가 왕복 일치(예: 14:00 입력 ↔ 05:00Z 저장 ↔ 14:00 표시).
- [ ] 채팅 `createdAt` 은 KST 시각으로 표시되고, `targetDate`(그룹핑 키)와 구분된다.

## 3. 반응형 (NFR-08)

- [ ] **≥1024px**: 캘린더(가변) + 채팅(360px) 2열, 각 열 독립 스크롤.
- [ ] **<1024px**: 캘린더 → 채팅 세로 스택, 가로 스크롤/붕괴 없음.
- [ ] 모달(일정/변경요청)이 좁은 화면에서 `max-h-[90vh]` 내부 스크롤로 잘리지 않음.

## 4. 교차 브라우저 (NFR-07)

- [ ] Chrome / Edge / Firefox / Safari 최신 2버전에서 로그인·캘린더·채팅·모달 동작 확인.

## 5. 권한 노출 (FE-13, UX)

- [ ] 팀원: `일정 추가`·일정 수정/삭제·요청 처리 버튼 미노출(강제는 서버).
- [ ] 팀장: 모든 통제 액션 노출.
